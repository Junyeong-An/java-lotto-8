# java-lotto-precourse

---
## 구현할 기능 목록
### 입력(Input)

- [ ] 로또 구입 금액 입력

* 1,000원 단위로 입력받는다.

* 1,000원으로 나누어 떨어지지 않으면 예외 발생 ([ERROR] 구입 금액은 1000원 단위여야 합니다.).

* 숫자가 아닌 값 입력 시 예외 발생 ([ERROR] 금액은 숫자만 입력 가능합니다.).

- [ ] 당첨 번호 입력

* 쉼표(,)로 구분된 6개의 숫자 입력.

* 1~45 범위를 벗어나면 예외 발생.

* 중복된 숫자가 있으면 예외 발생.

* 개수가 6개가 아니면 예외 발생.

- [ ] 보너스 번호 입력

* 1~45 범위 내의 정수.

* 당첨 번호와 중복될 경우 예외 발생.

### 로또 발행 (Lotto Issue)

- [ ] 구입 금액에 따라 로또 개수 계산 (금액 / 1000)

- [ ] Randoms.pickUniqueNumbersInRange(1, 45, 6)를 사용해 중복되지 않은 6개 번호 생성

- [ ] 각 로또 번호를 오름차순 정렬 후 저장

- [ ] 생성된 모든 로또를 출력
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
```

### 당첨 결과 계산 (Winning Result)

- [ ] 사용자가 구매한 모든 로또와 당첨 번호 비교

- [ ] 일치하는 번호의 개수 계산

- [ ] 5개 일치 시 보너스 번호 포함 여부 확인

- [ ] 등수별 결과 집계
```
등수	조건	상금
1등	6개 일치	2,000,000,000원
2등	5개 + 보너스	30,000,000원
3등	5개 일치	1,500,000원
4등	4개 일치	50,000원
5등	3개 일치	5,000원
```
### 출력(Output)

- [ ] 구매한 로또 개수 및 번호 목록 출력

- [ ] 당첨 통계 출력
```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```


- [ ] 수익률 = (총 당첨금 / 구매 금액) × 100
 * 소수점 둘째 자리에서 반올림 (String.format("%.1f", ratio))

### 예외 처리 (Exception Handling)

- [ ] 입력값이 잘못된 경우 IllegalArgumentException 발생

- [ ] 예외 메시지는 반드시 [ERROR]로 시작해야 함

- [ ] 예외 발생 시 해당 입력부터 다시 진행
